# Data availability and reproduction scope

The release includes figure-level data, species-level IBS selection evidence, and pseudonymized sample-level species abundance profiles with minimal disease-comparison labels.

| Released input | Contents | Role |
|---|---|---|
| `input/panel_a_lodo_auc.tsv` | 24 disease-by-project AUC estimates and bootstrap confidence intervals across 19 unique project accessions; aggregate case/control sample counts and analysis settings | Figure 1A; descriptive summaries in B; exploratory I² |
| `input/species_sets.tsv` | 300 CRC/CRA, 300 IBD and 81 Mars_2020 IBS selected species (681 membership rows) | Observed intersections in C and D |
| `input/species_detection_backgrounds.tsv` | 1,813 CRC/CRA, 1,357 IBD and 465 IBS background species (3,635 membership rows) | Group-specific sampling backgrounds for C |
| `input/ibs_species_selection.tsv` | Species-level abundance, differential-test and random-forest selection evidence for all 465 IBS background species, including eligibility and membership in the 81-species set | Documentation of IBS candidate selection |
| `Figure1_cohort_species_public.zip` | Sample-level MetaPhlAn 4 species abundance profiles and minimal case/control grouping files from 20 cohorts, with cohort/source tables and file hashes | Public processed abundance inputs supporting the cohort comparisons |

The companion archive contains 10 colorectal cohorts, 9 IBD cohorts and one IBS cohort, with 6,264 profiled samples and 934,240 abundance rows. Some colorectal cohorts contribute both adenoma and carcinoma comparisons. Samples are not necessarily distinct participants: repeated visits or longitudinal specimens can occur, and controls can be reused across disease comparisons. Comparison-level counts must not be summed to infer an independent participant count.

The profiles retain pseudonymized specimen keys, species identifiers and relative-abundance values in their source-export scale. Grouping files contain only the specimen key and applicable comparison labels. The archive is an analysis-eligible subset of processed profiles, not raw sequencing reads. Identifying demographic and free-text metadata are not distributed. Public project accessions and MetaLog source URLs are recorded where available. For Mars_2020, a project accession is unavailable in the supplied source metadata; the study code and public source URL identify the cohort. Source URLs containing `latest` can change; the distributed file hashes identify the supplied files.

The figure-reproduction code starts from aggregate AUC estimates, selected species memberships and detection backgrounds. It recomputes the displayed AUC summaries, exploratory heterogeneity, own-background overlap statistics and figure. The archive provides sample-level abundance inputs, but the model-training and initial species-screening code, individual predictions and raw reads are not included. The pinned software requirements describe the figure-reproduction environment; database and software versions for the initial profiling and model-training analyses are not comprehensively documented. This release therefore does not refit the nested models or rerun random-forest species screening from raw reads or profiles.

The IBS set comprises the 81 eligible Mars_2020 candidates ranked in the random-forest Top 50 in at least one of five stratified folds within its 465-species filtered background. All 81 were retained because the eligible count was below the Top-300 limit. Individual-species q values and absolute log2 fold changes were not thresholded for membership. `input/ibs_species_selection.tsv` contains species-level aggregate evidence; it contains no sample-level records. Its differential-test q values are distinct from the four BH-adjusted overlap q values in Figure 1C. Neither IBS membership nor membership in the other selected sets implies that every member is individually significant. IBS evidence comes from one cohort and does not represent cross-cohort replication. Species names and SGB identifiers are retained as supplied.
